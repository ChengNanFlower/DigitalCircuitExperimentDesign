# 实验7 基本寄存器设计

## 文件说明

### 源文件 (sources_1/new/)

- `Register_8bit.v` - 8位寄存器模块，包含异步清零和三态输出功能

- `USAGE_INSTRUCTIONS.md` - TCL脚本详细使用说明

## 功能说明

### Register_8bit 模块

实现一个8位带异步清零和输出使能的寄存器：

- CLK: 时钟输入（上升沿触发）
- CLR: 异步清零输入（高电平有效）
- OE_N: 输出使能输入（低电平有效）
- D[7:0]: 8位数据输入
- Q[7:0]: 8位数据输出（三态）

### 功能表

| OE_N | CLR | CLK        | D    | Q^(n+1)   | 功能         |
|------|-----|------------|------|-----------|--------------|
| 1    | x   | x          | x    | 高阻      | 禁止输出     |
| 0    | 1   | x          | x    | 0000 0000 | 清零并输出   |
| 0    | 0   | 0          | x    | Q^n       | 保持并输出   |
| 0    | 0   | ↑(上升沿)  | D    | D         | 置入数据并输出 |

## 使用说明

### 方法1: 手动在Vivado中操作

1. 在Vivado中创建新工程
2. 添加源文件和约束文件
3. 设置顶层模块为Top_Register
4. 运行综合和实现
5. 生成比特流文件并下载到FPGA
6. 通过拨动开关和按键验证寄存器功能

### 方法2: 使用自动化脚本

1. 打开Vivado Tcl控制台
2. 执行命令: `source ./regenerate_bitstream_simple.tcl`
3. 等待脚本执行完成
4. 下载生成的比特流文件到FPGA

详细使用说明请参阅 [USAGE_INSTRUCTIONS.md](USAGE_INSTRUCTIONS.md)

## 实验验证步骤

### 步骤1: 数据锁存功能验证

1. 通过SW[9:2]设置想要存储的数据，例如设置为10110101
2. 确保SW[0]=0（不清零），SW[1]=0（使能输出）
3. 按下BT按钮产生时钟上升沿
4. 观察现象: LED[7:0]应显示锁存的数据10110101
5. 期望结果: 寄存器成功锁存并输出设置的数据

### 步骤2: 清零功能验证

1. 在数据已锁存的状态下
2. 拨动SW[0]到高电平（1）
3. 观察现象: LED[7:0]全部熄灭（显示00000000）
4. 期望结果: 寄存器被异步清零，输出全为0
5. 将SW[0]恢复为低电平（0）

### 步骤3: 输出使能功能验证

1. 在数据已锁存的状态下
2. 拨动SW[1]到高电平（1）
3. 观察现象: LED[7:0]可能显示不确定状态或熄灭
4. 期望结果: 寄存器输出进入高阻态，LED显示不确定状态
5. 将SW[1]恢复为低电平（0）
6. 观察现象: LED[7:0]重新显示锁存的数据
7. 期望结果: 寄存器输出重新使能，显示锁存的数据

### 步骤4: 数据更新验证

1. 设置一组数据通过SW[9:2]，例如01010101
2. 确保SW[0]=0，SW[1]=0
3. 按下BT按钮
4. 观察现象: LED[7:0]显示01010101
5. 期望结果: 寄存器锁存新的数据
6. 更改SW[9:2]为另一组数据，例如11110000
7. 按下BT按钮
8. 观察现象: LED[7:0]显示11110000
9. 期望结果: 寄存器成功更新并输出新的数据

### 步骤5: 综合功能验证

1. 设置初始数据为11111111
2. 测试清零功能: SW[0]=1，观察LED全灭
3. 恢复SW[0]=0，设置数据为10101010
4. 按下BT按钮，观察LED显示10101010
5. 测试输出使能: SW[1]=1，观察LED进入高阻态
6. 恢复SW[1]=0，观察LED重新显示数据
7. 期望结果: 寄存器各项功能均正常工作

## 故障排除

如果遇到约束文件相关的错误，请尝试使用简化版约束文件(Register_Constraint_simple.xdc)。

如果寄存器不工作，请检查：

1. 时钟信号是否正确连接到BT按键
2. 所有控制信号(SW[1:0])是否正确设置
3. 约束文件中的管脚分配是否与实际硬件匹配
4. 数据输入信号(SW[9:2])是否正确设置
