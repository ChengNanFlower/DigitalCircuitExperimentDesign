## 实验 7 基本寄存器设计

### 5.7.1 实验目的

1. 学习寄存器的原理与设计方法。
2. 掌握输出使能端 $\overline{OE}$ (output enable) 的处理方法。

### 5.7.2 实验内容与原理

#### 1. 寄存器

计算机的CPU中包含很多专有和通用的寄存器，寄存器就是由统一时钟控制的触发器组成的。一个n位的寄存器由n个触发器构成，最常见的是由维持阻塞D触发器构成的D寄存器。

本实验要求设计一个8位带清零端和输出使能端的8D寄存器，其模块逻辑框图如**图5.19 (a)**所示，内部结构图如**图5.19 (b)**所示，表5.14是其功能表。

**表5.14 8位寄存器功能表**

| $\overline{OE}$ | CLR | CLK          | D | Q$^{n+1}$ | 功能           |
| ----------------- | --- | ------------ | - | ----------- | -------------- |
| 1                 | x   | x            | x | 高阻        | 禁止输出       |
| 0                 | 1   | x            | x | 0000 0000   | 清零并输出     |
| 0                 | 0   | 0            | x | Q$^{n}$   | 保持并输出     |
| 0                 | 0   | $\uparrow$ | D | D           | 置入数据并输出 |

从内部结构可以看出，该寄存器是由一个带清零端的8D寄存器和一个三态门构成。8D寄存器的CLR为异步清零端，当CLR=1时，寄存器清零；当CLR=0时，在CLK的上升沿，将输入端D的数据打入内部的8位触发器。显然，从**图5.19 (b)**可见：8D寄存器的这些操作并不受输出使能信号$\overline{OE}$的控制。但是，8D寄存器的输出送到8位三态门，只有当输出使能信号$\overline{OE}$=0时，三态门才打开，寄存器内部存储的数据可以通过Q端输出。否则，当$\overline{OE}$=1时，则禁止寄存器输出数据，即Q端为高阻状态，相当于8D寄存器的输出与外部的Q端断开连接；此时，8D寄存器中的数据并没有受影响，仅仅是不能输出而已。

#### 2. 三态门与输出使能功能

三态门（TS门，Tri-State Gate）的输出有逻辑0（L）、逻辑1（H）和高阻（HZ）三种状态，前两种状态为工作态，而高阻态也称为悬空态（Floating State），表示该门处于禁止输出状态，与后续电路断开。**图5.20**是三态缓冲门的符号。

**图5.20 三态缓冲门符号图**

```
  A ───┬─── F
       │
  EN ───┘
```

其中，EN是使能信号，低电平有效，EN=0，则F=A；EN=1，则输出F是高阻态，即F和A相当于断开隔离。三态缓冲门常用于将部件连接到总线，而连接到总线的各个部件，都要具有三态输出；由CPU来控制各个部件的三态使能信号，分时享用总线；即：只能有一个部件的输出使能信号有效，可将该部件的数据送上总线，避免总线上的数据引起冲突。

**图5.20所示的1位三态缓冲门的Verilog HDL描述如下：**

```verilog
// 方法1：
assign F = EN_ ? 1'bz : A;

// 方法2：
always @(*)
    if (!EN_) F = A;
    else F = 1'bz;
```

可以方便地将上述代码改造成8位三态缓冲门。也有一些三态缓冲门是双向的，比如74LS245三态缓冲器，由方向控制信号DIR控制数据的传输方向，当DIR=1，则信号由B→A传输；当DIR=0，则信号由A→B传输。显然，三态缓冲器只是用于传输数据，它不具备存储数据的能力。

基于上面的原理，以及前述的异步清零信号的处理方法，请自行写出本需求的带异步清零端CLR和输出使能端$\overline{OE}$的8D寄存器的模块。

### 5.7.4 实验步骤

1. 在Vivado中创建新工程，编写规定功能的8位寄存器模块的程序代码。
2. 编写激励代码，观察与分析仿真波形，确保模块逻辑正确；尤其要验证CLR信号和$\overline{OE}$的控制逻辑是否正确。
3. 新建管脚约束文件：

   - 时钟输入CLK：配置到1个按钮上；
   - 控制信号CLR和$\overline{OE}$：配置到2个开关上；
   - 数据输入D[7:0]：配置到8个开关上；
   - 输出Q[7:0]：接到8个LED灯上。
4. 生成*.bit文件，下载到实验设备的FPGA芯片中。
5. 板级实验：拨动控制信号以及数据输入所对应的开关，并按下CLK脉冲对应的按钮，观察LED灯的情况，记录实验结果到**表5.15**中，分析实验结果是否正确。尤其需要验证异步清零、数据打入、三态输出使能的功能。
