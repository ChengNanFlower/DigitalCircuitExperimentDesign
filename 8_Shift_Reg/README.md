# 实验8 移位寄存器设计

## 简介

本实验实现了一个8位双向移位寄存器模块74LS198，具备以下功能：

- 异步清零
- 保持功能
- 右移1位
- 左移1位（通过并行输入）

## 功能说明

### 移位寄存器模块 (Shift_Reg_8bit.v)

- **异步清零 (CR)**: 低电平有效
- **移位控制 (SI)**:
  - SI=0: 保持当前值
  - SI=1: 移位操作
- **并行输入 (DI[7:0])**: 用于左移时加载数据
- **时钟输入 (CP)**: 上升沿触发
- **并行输出 (Q[7:0])**: 8位数据输出
- **串行输出 (SQ)**: 最低位串行输出

### 控制逻辑

根据真值表：

1. CR=0: 异步清零
2. CR=1且SI=0: 保持
3. CR=1且SI=1且DI有输入: 左移（加载并行数据）
4. CR=1且SI=1且DI无输入: 右移1位

## 使用方法

1. 打开Vivado并加载项目文件 `8_Shift_Reg.xpr`
2. 运行综合和实现
3. 生成比特流并下载到FPGA
4. 使用开关和按键控制移位寄存器的操作

## 实验验证步骤

### 步骤1: 异步清零功能验证

1. 拨动SW[0]到低电平(0)
2. 观察现象: LED[7:0]全部熄灭(显示00000000)
3. 期望结果: 移位寄存器被异步清零，所有输出为0
4. 将SW[0]恢复为高电平(1)

### 步骤2: 保持功能验证

1. 设置移位寄存器中的数据，例如10110101
2. 拨动SW[1]到低电平(0)
3. 按下BT按键多次
4. 观察现象: LED[7:0]显示的数据保持不变
5. 期望结果: 移位寄存器保持当前数据不变

### 步骤3: 右移功能验证

1. 首先通过左移功能加载初始数据到移位寄存器中：
   - 设置SW[0]=1(不清零)
   - 设置SW[1]=1(移位模式)
   - 通过SW[10:3]设置想要加载的并行数据，例如11110000
   - 按下BT按键，观察LED[7:0]显示设置的数据
2. 确保SW[0]=1(不清零)，SW[1]=1(移位模式)
3. 确保SW[10:3]全部为0(无并行输入) - 这是触发右移操作的关键条件
4. 按下BT按键一次
5. 观察现象: LED[7:0]显示的数据右移1位，最低位移出到SQ_OUT
6. 期望结果: 数据右移1位，原最低位通过SQ_OUT输出
7. 继续按下BT按键，观察数据继续右移

### 步骤4: 左移功能验证（并行加载）

1. 拨动SW[0]到低电平(0)清零寄存器
2. 拨动SW[0]回到高电平(1)
3. 通过SW[10:3]设置想要加载的并行数据，例如10110101
4. 确保SW[1]=1(移位模式)
5. 按下BT按键
6. 观察现象: LED[7:0]立即显示SW[10:3]设置的并行数据
7. 期望结果: 移位寄存器加载并行输入的数据

### 步骤5: 串行输出验证

1. 设置移位寄存器中的数据为10110101
2. 确保SW[0]=1，SW[1]=1，SW[10:3]=00000000
3. 观察SQ_OUT(LED8)的状态
4. 按下BT按键一次
5. 观察现象: 最低位通过SQ_OUT输出，数据右移
6. 期望结果: 每次右移时，原最低位通过SQ_OUT输出

### 步骤6: 综合功能验证

1. 加载初始数据11110000
2. 进行右移操作，观察数据移动过程
3. 清零后加载新数据01010101
4. 进行左移操作（并行加载）
5. 交替进行右移和左移操作
6. 期望结果: 移位寄存器各项功能均正常工作

## 功能表

| CR | SI | DI[7:0] | CP     | 功能         |
|----|----|---------|--------|--------------|
| 0  | x  | x       | x      | 异步清零     |
| 1  | 0  | x       | x      | 保持         |
| 1  | 1  | 非全0   | ↑      | 左移（加载） |
| 1  | 1  | 全0     | ↑      | 右移         |

注:

- CR为异步清零信号，低电平有效
- SI为移位控制信号
- DI[7:0]为并行数据输入
- CP为时钟输入，上升沿触发

## 故障排除

如果移位寄存器不工作，请检查：

1. 时钟信号是否正确连接到BT按键
2. 所有控制信号(SW[1:0])是否正确设置
3. 约束文件中的管脚分配是否与实际硬件匹配
4. 并行数据输入信号(SW[10:3])是否正确设置
