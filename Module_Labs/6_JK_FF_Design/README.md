## 功能说明

### JK_FlipFlop 模块

实现一个具有异步置位和复位功能的JK触发器：

- CP: 时钟输入（下降沿触发）
- n_SD: 异步置位输入（低电平有效）
- n_RD: 异步复位输入（低电平有效）
- J: 激励输入J
- K: 激励输入K
- Q: 输出Q
- Q_n: 输出Q的反相

### 功能表

| J | K | Q^n | Q^(n+1) | 功能     |
|---|---|-----|---------|----------|
| 0 | 0 | Q   | Q       | 保持     |
| 0 | 1 | Q   | 0       | 置0      |
| 1 | 0 | Q   | 1       | 置1      |
| 1 | 1 | Q   | ~Q      | 翻转     |

异步控制信号优先级高于时钟控制：

- 当n_SD=0时，Q强制为1（置位）
- 当n_RD=0时，Q强制为0（复位）

| 信号 | 管脚 | 开关编号 | 说明 |

| SW[2] (n_SD1) | U17 | SW2 | 第1个JK触发器的异步置位 |
| SW[3] (n_RD1) | U16 | SW3 | 第1个JK触发器的异步复位 |
| SW[4] (J2) | V14 | SW4 | 第2个JK触发器的J输入 |
| SW[5] (K2) | U13 | SW5 | 第2个JK触发器的K输入 |
| SW[6] (n_SD2) | U12 | SW6 | 第2个JK触发器的异步置位 |
| SW[7] (n_RD2) | U11 | SW7 | 第2个JK触发器的异步复位 |

## 使用说明

### 方法1: 手动在Vivado中操作

1. 在Vivado中创建新工程
2. 添加源文件和约束文件
3. 设置顶层模块为Top_74LS76
4. 运行综合和实现
5. 生成比特流文件并下载到FPGA
6. 通过拨动开关和按键验证JK触发器功能

如果提供了重新生成比特流的脚本，可以按照以下步骤操作：

4. 下载生成的比特流文件到FPGA

## 实验验证步骤

### 第1个JK触发器验证（使用SW[3:0]控制，LED[1:0]观察）

#### 步骤1: 异步复位功能测试

1. 将SW[3]拨到低电平（0）
2. 观察现象: LED[0]应为0，LED[1]应为1
3. 期望结果: 第1个JK触发器被异步复位，Q=0，Q_n=1
4. 将SW[3]恢复为高电平（1）

#### 步骤2: 异步置位功能测试

1. 将SW[2]拨到低电平（0）
2. 观察现象: LED[0]应为1，LED[1]应为0
3. 期望结果: 第1个JK触发器被异步置位，Q=1，Q_n=0
4. 将SW[2]恢复为高电平（1）

#### 步骤3: 保持功能测试

1. 设置SW[0]=0, SW[1]=0
2. 确保SW[2]=1, SW[3]=1（异步控制信号无效）
3. 按下BT[0]按钮几次
4. 观察现象: LED输出应保持不变
5. 期望结果: 在时钟下降沿，触发器保持原有状态

#### 步骤4: 置0功能测试

1. 设置SW[0]=0, SW[1]=1
2. 确保SW[2]=1, SW[3]=1（异步控制信号无效）
3. 按下BT[0]按钮
4. 观察现象: LED[0]应变为0，LED[1]应变为1
5. 期望结果: 在时钟下降沿，触发器被置0

#### 步骤5: 置1功能测试

1. 设置SW[0]=1, SW[1]=0
2. 确保SW[2]=1, SW[3]=1（异步控制信号无效）
3. 按下BT[0]按钮
4. 观察现象: LED[0]应变为1，LED[1]应变为0
5. 期望结果: 在时钟下降沿，触发器被置1

#### 步骤6: 翻转功能测试

1. 设置SW[0]=1, SW[1]=1
2. 确保SW[2]=1, SW[3]=1（异步控制信号无效）
3. 按下BT[0]按钮一次
4. 观察现象: LED输出状态应翻转
5. 期望结果: 在时钟下降沿，触发器输出翻转
6. 再次按下BT[0]按钮
7. 观察现象: LED输出状态再次翻转
8. 期望结果: 触发器输出再次翻转

### 第2个JK触发器验证（使用SW[7:4]控制，LED[3:2]观察）

重复上述相同的操作步骤，但使用SW[7:4]作为输入，观察LED[3:2]的输出。

## 预期结果

1. 异步置位和复位功能应立即生效，不受时钟影响
2. 在时钟下降沿，根据J、K输入的不同组合，触发器应正确执行保持、置0、置1或翻转操作
3. Q和Q_n输出应始终互为反相
4. 两个JK触发器应独立工作，互不影响

## 功能表

| SW[2] | SW[3] | SW[0] | SW[1] | BT[0] | 功能     |
|-------|-------|-------|-------|--------|----------|
| 0     | x     | x     | x     | x      | 异步置位 |
| x     | 0     | x     | x     | x      | 异步复位 |
| 1     | 1     | 0     | 0     | ↓      | 保持     |
| 1     | 1     | 0     | 1     | ↓      | 置0      |
| 1     | 1     | 1     | 0     | ↓      | 置1      |
| 1     | 1     | 1     | 1     | ↓      | 翻转     |

注:

- SW[2]为第1个JK触发器的异步置位信号，低电平有效
- SW[3]为第1个JK触发器的异步复位信号，低电平有效
- SW[0]为第1个JK触发器的J输入
- SW[1]为第1个JK触发器的K输入
- BT[0]为时钟输入，下降沿触发

## 注意事项

1. 时钟采用下降沿触发，即在BT[0]从高电平变为低电平时触发
2. 异步控制信号（n_SD和n_RD）为低电平有效
3. 在进行功能测试时，确保异步控制信号处于无效状态（高电平）
4. 每次改变输入后，需要通过按下BT[0]按钮来提供时钟脉冲才能看到输出变化（除非是异步控制）

## 故障排除

如果JK触发器不工作，请检查：

1. 时钟信号是否正确连接到BT按键
2. 所有控制信号(SW[7:0])是否正确设置
3. 约束文件中的管脚分配是否与实际硬件匹配
4. 异步控制信号是否处于正确状态（高电平为无效状态）
